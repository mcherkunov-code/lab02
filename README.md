# Лабораторная работа №2: Потоковый анализатор логов (StreamStats)

Консольная утилита на Python для анализа лог-файлов в форматах CSV и JSONL. 

Главная идея этой работы — научиться обрабатывать большие объёмы данных потоково. Вместо того чтобы загружать весь многомегабайтный файл в память целиком через `read()` или обычные списки, программа читает файл построчно с помощью генераторов (`yield`). За счёт этого утилита потребляет минимум оперативной памяти независимо от размера логов.


## Что умеет программа

1. Потоковое чтение файлов:
   * Поддерживает форматы `.csv` и `.jsonl`.
   * Автоматически определяет формат файла по его расширению или принимает принудительный формат через флаг `--format`.
   * Умеет объединять в один общий поток сразу несколько файлов, переданных в командной строке.

2. Валидация записей:
   * Проверяет наличие всех обязательных полей: время (`timestamp`), уровень (`level`), источник (`source`), сообщение (`message`).
   * Проверяет формат даты и времени по стандарту ISO 8601.
   * Контролирует допустимые уровни логов: `DEBUG`, `INFO`, `WARNING`, `ERROR`, `CRITICAL`.

3. Сбор статистики за один проход:
   * Считает общее количество событий.
   * Считает количество событий по каждому уровню и по каждому источнику.
   * Находит самое раннее и самое позднее время события (`start_time` и `end_time`).
   * Формирует топ-5 источников, где чаще всего возникали ошибки уровней `ERROR` и `CRITICAL` (с правильной сортировкой: сначала по убыванию количества ошибок, а при равенстве — по алфавиту источника).

4. Гибкая обработка битых строк:
   * По умолчанию при встрече повреждённой строки или невалидных данных программа сразу останавливается, пишет ошибку в лог и завершается с кодом `2`.
   * Если указан флаг `--skip-invalid`, повреждённые записи не роняют программу: они пропускаются, в консоль пишется предупреждение `WARNING`, а в итоговом отчёте появляется поле `invalid_records` с числом пропусков.

5. Вывод результатов:
   * Печатает готовый JSON-отчёт прямо в консоль или сохраняет в отдельный файл по флагу `-o` / `--output`.
   * Корректно сохраняет русский текст (кириллицу) благодаря `ensure_ascii=False`.


## Дополнительные возможности(доп. задания)

- Ленивая фильтрация событий: фильтрация по уровню (`--level`), источнику (`--source`) и диапазону времени (`--since`, `--until`) без загрузки данных в память.
- Экспорт отчёта в CSV: сохранение результатов в табличном виде (если файл указан с расширением `.csv`) без повторного пересчёта данных.

## Установка и запуск

Все команды выполняются из корневой папки проекта в терминале macOS / Linux.

1. Настройка виртуального окружения
Создаём изолированное окружение .venv, чтобы не засорять системный Python:
`python3 -m venv .venv`
`source .venv/bin/activate`

(После активации в начале строки терминала появится префикс (.venv)).

2. Установка зависимостей
Устанавливаем наш пакет в текущее окружение в режиме редактирования (-e), а также библиотеки для тестов и проверки кода:
`pip install -e .`
`pip install pytest ruff`


## Примеры использования утилиты

- Посмотреть справку по командам и флагам
`python -m streamstats --help`
`python -m streamstats analyze --help`

- Анализ одного файла с выводом отчёта в терминал
`python -m streamstats analyze logs.jsonl`

- Анализ нескольких файлов и сохранение отчёта в файл
`python -m streamstats analyze logs_part1.csv logs_part2.jsonl -o result.json`

- Обработка файла с пропуском битых строк
Если в файле есть строки с пропущенными полями или кривыми датами:
`python -m streamstats analyze broken_logs.jsonl --skip-invalid`

- Принудительное указание формата
Если у файла нестандартное расширение (например, .txt или .log):
`python -m streamstats analyze app.log --format jsonl`

- Фильтрация только ошибок сервиса авторизации за определённый период:
`python -m streamstats analyze logs.jsonl --level ERROR --source auth --since 2026-10-18T10:00:00+03:00`

- Выгрузка результатов напрямую в CSV-файл:
`python -m streamstats analyze logs.csv -o report.csv`

## Тестирование и проверка стиля

- Запуск тестов
В проекте написаны автоматические тесты через pytest, покрывающие все базовые сценарии (парсеры, пустые файлы, битые строки, склейка файлов, кириллица и интеграционный запуск через subprocess):
`python -m pytest -v`

- Проверка стиля кода
Код полностью проверен линтером ruff на соответствие стандартам PEP 8 и чистоту импортов:
`ruff check .`
